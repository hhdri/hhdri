## Hi, I'm Majid

I'm a machine learning engineer at Picnic, based in Amsterdam. Outside of work, I enjoy systems programming in Rust and writing about math and statistics on [majid.blog](https://majid.blog).

Currently building SQLite from scratch in Rust.

### Projects

- [codecrafters-sqlite-rust](https://github.com/hhdri/codecrafters-sqlite-rust) (2026) – A barebones SQLite implementation in Rust for the CodeCrafters "Build Your Own SQLite" challenge. Zero dependencies: SQL parsing, B-tree traversal, and record decoding are all implemented from scratch against the official SQLite file format spec.
- [codecrafters-shell-rust](https://github.com/hhdri/codecrafters-shell-rust) (2025) – A POSIX-compliant shell in Rust for the CodeCrafters "Build Your Own Shell" challenge: command parsing, a REPL, builtin commands, and running external programs.
- [codecrafters-shell-cpp](https://github.com/hhdri/codecrafters-shell-cpp) (2025) – My earlier take on the same "Build Your Own Shell" challenge, this time in C++.
- [agglo](https://github.com/hhdri/agglo) (2023) – Fast agglomerative (hierarchical) clustering in Rust.
- [UTank](https://github.com/hhdri/UTank) (2020) – A tank game in Java. This was the course-end project for the "Advanced Programming" course, back when I was a bachelor's student.
- [pizza](https://github.com/hhdri/pizza) (2017) – An algorithm for dividing a circle into *n* equal areas from any given point, solved numerically in a Jupyter notebook. I also wrote a [blog post](https://majid.blog/pizza.html) about it.
